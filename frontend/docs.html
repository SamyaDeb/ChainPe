ChainPe Documentation

The complete guide to building, deploying, and using AI agent micropayments on Algorand with the x402 payment protocol.

Overview

ChainPe is an AI Agent Marketplace built on the Algorand blockchain. It enables AI agents to autonomously discover API services, pay for them with native ALGO micropayments, and receive results — all without human intervention.

ChainPe implements the x402 payment protocol, based on the HTTP 402 "Payment Required" status code. This is how the web was originally designed to handle payments — ChainPe finally brings it to life with blockchain-backed micropayments.

One-Liner ChainPe lets AI agents pay for APIs autonomously using Algorand micropayments — no human approval, no subscriptions, just pay-per-request with native ALGO.

Key Features

  • x402 Protocol — Real HTTP 402 "Payment Required" implementation
  • Native ALGO Payments — No wrapped tokens, no bridges, pure native payments
  • 4-Second Finality — Algorand confirms transactions in ~4 seconds
  • Near-Zero Fees — Transaction fees of ~0.001 ALGO make micropayments viable
  • AI SDK Integration — Built on Vercel AI SDK, works with any LLM provider
  • Direct Settlement — Providers receive ALGO directly to their wallet
  • Developer-Friendly — npm install @chainpe/agent and start paying for APIs

Quick Start

Get up and running with ChainPe in under 5 minutes.

1. Install the SDK

npm install @chainpe/agent

2. Configure your agent

// chainpe.config.js
import { createChainPeAgent } from '@chainpe/agent';

const agent = createChainPeAgent({
  // Your Algorand wallet mnemonic (testnet)
  mnemonic: process.env.ALGO_MNEMONIC,

  // Network configuration
  network: 'testnet',

  // Safety limits
  maxPricePerRequest: 0.1,  // max ALGO per single request
  maxTotalSpend: 5.0,       // max ALGO total budget

  // AI provider (optional, for autonomous discovery)
  aiProvider: {
    model: 'gpt-4',
    apiKey: process.env.OPENAI_API_KEY,
  }
});

3. Make your first paid API call

// Discover and pay for a weather service
const result = await agent.run(
  'Get the current weather for London'
);

console.log(result);
// {
//   data: { city: 'London', temp: '12°C', ... },
//   payment: {
//     txId: 'ALGO_TX_ABC123...',
//     amount: 0.05,
//     currency: 'ALGO'
//   }
// }

4. Verify on-chain

Every payment creates a real transaction on the Algorand blockchain. You can verify any transaction on the Algorand Explorer.

The x402 Protocol

HTTP 402 "Payment Required" has been in the HTTP specification since HTTP/1.1 (1997), but was "reserved for future use." ChainPe implements the x402 extension of this standard, enabling machine-to-machine payments over HTTP.

The x402 Response

When a service requires payment, it responds with HTTP status 402 and a payment requirement header:

HTTP/1.1 402 Payment Required
X-Payment-Required: {
  "network": "algorand",
  "receiver": "ALGO_ADDRESS_HERE",
  "amount": 0.05,
  "asset": "ALGO",
  "memo": "weather-api-request-12345"
}

How It Works

Step 1: Service Discovery

AI agents discover available services in the ChainPe marketplace. Each service has a listing that includes:

  • Endpoint URL — The API endpoint to call
  • Price — Cost per request in ALGO
  • Description — What the service provides
  • Provider wallet — The Algorand address to pay

Step 2: Autonomous Payment

When the agent makes a request, the x402 proxy intercepts the 402 response and handles payment automatically:

// This happens automatically inside the SDK
const payment = await algoSdk.makePaymentTxn(
  agentWallet.address,        // sender
  serviceProvider.address,     // receiver
  0.05 * 1e6,                 // amount in microALGO
  undefined,                   // close remainder to
  'chainpe:weather:req-123'   // memo/note
);

const signedTxn = payment.signTxn(agentWallet.sk);
const txResult = await algodClient.sendRawTransaction(signedTxn).do();

Step 3: Verification & Response

The x402 proxy verifies the payment landed on-chain before forwarding the request to the API provider. The provider's server only processes requests with confirmed payments.

Zero Intermediary Risk ChainPe never holds funds. Payments go directly from the agent's wallet to the provider's wallet. The proxy only verifies — it never touches the money.

Agent SDK

The @chainpe/agent SDK provides a high-level interface for AI agents to interact with paid APIs.

createChainPeAgent(config)

Creates a new ChainPe agent instance with the given configuration.

import { createChainPeAgent } from '@chainpe/agent';

const agent = createChainPeAgent({
  mnemonic: string,            // Algorand wallet mnemonic
  network: 'testnet' | 'mainnet',
  maxPricePerRequest: number,  // Max ALGO per request
  maxTotalSpend: number,       // Budget cap in ALGO
  aiProvider?: {
    model: string,             // LLM model name
    apiKey: string,            // Provider API key
  }
});

agent.run(prompt, options?)

Sends a natural language prompt to the agent. The agent discovers relevant services, pays for them, and returns the result.

const result = await agent.run(
  'Get weather for London, Paris, and Tokyo',
  {
    provider: 'Weather',       // Optional: specific service
    maxRetries: 3,             // Retry on failure
  }
);

// result.data    → API response data
// result.payment → { txId, amount, currency }
// result.cost    → Total ALGO spent

agent.getBalance()

Returns the current ALGO balance of the agent's wallet.

const balance = await agent.getBalance();
// { available: 4.75, spent: 0.25, unit: 'ALGO' }

agent.getTransactions()

Returns a list of all transactions made by the agent.

const txns = await agent.getTransactions();
// [
//   { txId: 'ABC...', amount: 0.05, service: 'Weather', timestamp: ... },
//   { txId: 'DEF...', amount: 0.05, service: 'Weather', timestamp: ... },
// ]

For API Providers

Any API can become a paid service on ChainPe. Here's how to onboard your API:

1. Register your service

// Register with the ChainPe marketplace
const service = await chainpe.registerService({
  name: 'Weather API',
  description: 'Real-time weather data for any city',
  endpoint: 'https://api.yourservice.com/weather',
  price: 0.05,               // ALGO per request
  wallet: 'YOUR_ALGO_ADDRESS',
  category: 'data',
});

2. Add x402 payment middleware

import { x402Middleware } from '@chainpe/provider';

// Express.js example
app.use('/api/weather', x402Middleware({
  price: 0.05,
  wallet: 'YOUR_ALGO_ADDRESS',
  network: 'testnet',
}));

app.get('/api/weather', (req, res) => {
  // Only reached after verified payment
  const city = req.query.city;
  res.json({ city, temp: '12°C', humidity: '65%' });
});

3. Receive payments

Payments are received directly to your Algorand wallet. No intermediary holds funds. The x402 proxy verifies the payment hit the blockchain before forwarding requests to your API.

Revenue Model You set your own price per request. ChainPe takes zero commission during beta. All ALGO goes directly to your wallet.

Security

Spending Controls

  • maxPricePerRequest — Caps the maximum ALGO an agent can spend per single API request
  • maxTotalSpend — Sets a total budget. When exhausted, payments fail gracefully
  • Balance limits — Agent wallets have a finite balance. When empty, all requests stop
  • Dry-run mode — Test your agent without making real payments

Wallet Security

Important Never commit your mnemonic to version control. Always use environment variables or a secrets manager. For production, use a dedicated agent wallet with limited funds.

On-Chain Verification

Every payment is verifiable on the Algorand blockchain. The x402 proxy checks:

  1. Transaction exists on-chain
  2. Correct amount was sent to the correct receiver
  3. Transaction memo matches the request ID
  4. Transaction is confirmed (finality reached)

FAQ

Why not just use Stripe?

Stripe requires merchant accounts, human verification, and charges 2.9% + $0.30 per transaction. A $0.05 micropayment would cost more in fees ($0.30 minimum) than the payment itself. Algorand transaction fees are ~0.001 ALGO (~$0.0002).

Why Algorand specifically?

Speed and cost. AI agents need instant settlement — Algorand confirms in 4 seconds. The fees are low enough that even $0.01 payments make economic sense. No other Layer-1 provides this combination for micropayments.

How do providers get paid?

Directly to their Algorand wallet. No intermediary holds funds. The x402 proxy only verifies that the payment hit the chain before forwarding the API request.

What prevents agents from overspending?

Multiple safeguards: wallet balance limits, maxPricePerRequest caps, maxTotalSpend budget limits, and graceful failure when funds are exhausted.

Is ChainPe open source?

Yes. The SDK, proxy, and agent are all open source. View the code on GitHub.

Can I use mainnet?

ChainPe currently runs on Algorand testnet. Mainnet support is coming soon. The configuration switch is a single line change: network: 'mainnet'.
