# ChainPe marketing page

A one-page Next.js site about ChainPe on Arc: AI agents find services, pay in USDC and get results.

The main site is `apps/landing`, and the provider dashboard is `apps/arc-dashboard`. `/docs` here redirects to the
docs at https://chainpe.vercel.app/docs.

## Run locally

```bash
npm install
npm run dev                 # http://localhost:3000
```

## Verify

```bash
npm run typecheck
npm run build
```
